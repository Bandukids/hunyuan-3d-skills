# HY-3D-UV 接入参考

来源：[腾讯云 UV 展开调用指南](https://cloud.tencent.com/document/product/1823/137777)。核对：2026-09-14；文档更新：2026-09-09。已做离线模拟验证，尚未提交真实 UV 任务。

## 输入与预检

使用 HTTPS FBX/OBJ/GLB 模型链接。文档标注 60M、3 万面和最多 100 个组件/连通域；未说明 M 的字节进制，也未解释面数按多边形还是三角面统计。

客户端保守按 `≤60,000,000` 字节和 `≤30,000` 面校验已知测量值。这是本地约定，不能当作服务端边界实测。核查模型的组件和连通域数量，任一已知超限时先处理模型；几何超限可使用网格技能处理副本并重新检查，不自动提交前置付费任务。

可选本地预检参数：

| 参数 | 含义 | 接受范围 |
|---|---|---|
| `--input-size-bytes` | 已核验输入字节数 | 1～60,000,000 |
| `--face-count` | 已核验输入面数 | 1～30,000 |
| `--component-count` | 已核验组件/连通域数量 | 1～100 |

这些值不发送给 API，不是减面目标；缺省表示未知。预检不下载远端模型，不证明其实际几何符合限制。

## 请求和恢复

提交 `POST /v1/api/3d/submit`：

```json
{"model":"hy-3d-uv","file":{"url":"https://example.com/model.fbx"}}
```

可选 `--file-type fbx|obj|glb` 对应 `file.type`，不指定时省略；若与链接扩展名冲突则拒绝。不要使用纹理接口的 `file_3d`，也不要加入提示词、参考图、PBR、保留 UV、分辨率或手动切缝参数。

`uv` / `unwrap` 提交后等待并下载；`submit --model uv` 只提交。查询 `POST /v1/api/3d/query` 使用 `{"model":"hy-3d-uv","id":"JOB_ID"}`。恢复须带 `--model uv` 和原地域，不能使用查询默认的纹理模型。

默认并发 1，任务 ID 有效期 24 小时。下载完成响应中全部 `data` 资源；示例包含 OBJ、FBX、图片，实际格式以返回为准，接口没有输出格式选择字段。图片不能证明 UV 展开质量，应检查返回模型中的 UV。

## 后续纹理

将 UV 结果中的可用 OBJ/GLB 链接交给 `texture`，配文字或参考图，按需加 `--enable-keep-uv`。若只有 FBX，先准备纹理接口支持的格式。该流程是两个独立云端任务，UV 展开不同时生成纹理，也不等于材质烘焙。
