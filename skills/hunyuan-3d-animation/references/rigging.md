# HY-3D-Rigging 接入参考

来源：[腾讯云绑骨蒙皮调用指南](https://cloud.tencent.com/document/product/1823/137779)。核对：2026-09-14；文档更新：2026-09-09。已做离线模拟验证，尚未提交真实绑骨任务。

## 输入边界

接受 FBX/GLB 人物或动物模型，文件不超过文档标注的 60mb。字节进制未说明，客户端对已知大小保守按 60,000,000 字节检查。

人形采用 A Pose 或 T Pose，保持静态，移除人体以外的附带对象，减少松散衣物、饰品和复杂头发。非人形建议是姿态简单的单个二足、四足或鸟类生命体；不支持动作模板。文档未给出面数、骨骼数量或命名规范限制，不套用 UV 接口的 3 万面约束。

`--character-type` 和 `--input-size-bytes` 是客户端可选的已知元数据，既不自动检测模型，也不属于请求字段。可用模板前须核对人形分类；只提供 URL 时不能证明模型满足形态要求。

## 请求和动作

提交 `POST /v1/api/3d/submit`：

```json
{"model":"hy-3d-rigging","file_3d":{"url":"https://example.com/character.fbx"}}
```

可选 `file_3d.type` 使用 `fbx` / `glb`，对应 `--file-type`，未指定即省略。有扩展名时须与类型一致。只有显式选择模板才附加整数 `motion_type`；不发送 `file`、提示词、时长、目标骨架或输出格式等未定义字段。

动作编号 1～48 可用 `list-motions` 离线查看，映射维护在客户端 `MOTIONS`；模板列表查询与单测不访问云端，任务 `query` 会调用云端。该参数是同一绑骨任务的可选模板；文字生成动作使用 [motion.md](motion.md) 中的独立接口。未指定模板时省略，输出仍需核对服务端实际结果。

## 查询和资产

查询 `POST /v1/api/3d/query`，内容为 `{"model":"hy-3d-rigging","id":"JOB_ID"}`。任务恢复时保留原地域和模型；超时或失败不自动重复提交。

下载完成响应中所有 `data` 的 `type` / `url` 资源，示例返回 FBX；文件类型以实际响应为准。生成成功不能证明权重、动作或引擎兼容性，应检查返回模型的骨架、变形及所选模板动作。
