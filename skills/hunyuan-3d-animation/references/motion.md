# HY-3D-Motion 接入参考

来源：[腾讯云文生动作调用指南](https://cloud.tencent.com/document/product/1823/137780)。核对：2026-09-14；文档更新：2026-09-09。已做离线模拟验证，尚未提交真实文生动作任务。

## 参数和任务

提交 `POST /v1/api/3d/submit`，最简请求：

```json
{"model":"hy-3d-motion","prompt":"A person walks forward"}
```

`prompt` 最多 128 字符。可选 `duration` 为 1～12 秒，默认 5；`enable_mesh` 默认 true，控制是否附带蒙皮网格；`enable_rewrite`、`enable_duration_est` 默认 false，分别扩写描述和自动估算时长。客户端保留显式布尔 false，未指定的选项省略，不推测自动时长与固定时长的优先级。

查询 `POST /v1/api/3d/query` 使用 `{"model":"hy-3d-motion","id":"JOB_ID"}`。`query --model motion` 保留原任务和地域，不能使用客户端默认的绑骨模型。按共用流程处理排队、运行、完成和失败，下载返回的所有资源；示例为动画 FBX，未提供输出格式、帧率、循环或根运动开关。

## 重定向对象的限制

`retarget_file` 是可选对象，只支持文档所述的混元动画模板接口生成的模型。文档没有列出内部字段，也没有重定向请求示例。客户端不构造 `url` / `type` 或猜测其它字段，不把普通 FBX、任意已绑骨模型或非人形骨架认定为兼容来源。

已拥有腾讯确认或验证过的原生对象时，可将该对象单独保存在 UTF-8 JSON 文件中，通过 `--retarget-file-json` 读取。客户端检查非空对象、重复键和非有限数值，并将对象原样置于请求的 `retarget_file`；不会把整个 JSON 文件当模型上传，也不把对象编码成字符串。该校验只证明语法可用，不证明结构或资产兼容。

没有已确认对象时可正常执行无重定向的文生动作；若用户要求应用到自己的角色，应先取得缺失的对象结构及来源信息。不要静默删除重定向要求、自动重新绑骨或承诺任意骨架重定向。
